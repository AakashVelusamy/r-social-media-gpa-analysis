## Overview
This project analyzes the relationship between students' GPA and social media usage using statistical tools, forecasting models, and data visualization techniques. With a **menu-driven interface**, users can generate summary statistics, perform ANOVA and hypothesis tests, visualize data, and make forecasts using ARIMA models. This analysis identifies significant effects of social media usage on GPA and tests specific hypotheses related to usage patterns.

## Key Features
- **Menu-Driven Interface**  
  Allows users to easily select actions, including generating summary statistics, conducting ANOVA, performing hypothesis testing, and generating various plots.

- **Manual ANOVA Analysis**  
  Calculates between-group and within-group variances to assess the effect of different levels of social media usage (Low, Moderate, High) on GPA.

- **Hypothesis Testing**  
  Provides detailed t-tests to compare GPA differences between high and low usage groups and tests whether moderate usage correlates with higher GPA than high usage.

- **Forecasting Using ARIMA**  
  Implements time series forecasting with ARIMA to predict future GPA trends, offering insights into potential long-term effects of social media behavior.

- **Visualization Tools**  
  Offers bar plots, box plots, histograms, and time series plots to visually explore data distribution and trends.

## Summary
This program offers a comprehensive approach to understanding the impact of social media usage on academic performance. By combining statistical analysis, forecasting, and visualization, it provides valuable insights that help educators and students make informed decisions about screen time and academic balance.
